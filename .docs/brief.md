# Portaria Digital

- One-line positioning: App de gestão de moradores para condomínios com pesquisa rápida
- Target users: Porteiros e síndicos de condomínios
- Core features:
  1. Lista completa de moradores com apartamento, bloco, telefone, e-mail, CPF e status
  2. Pesquisa por nome, apartamento, bloco ou telefone (tempo real)
  3. Cadastro, edição e remoção de moradores
- Important features (P1):
  1. Filtro por status ativo/inativo
  2. Ordenação por apartamento ou nome
- Device strategy: adaptive
- Design style: Portaria corporativa – azul institucional, cards brancos, interface limpa
- Technical constraints: Next.js + Drizzle + PostgreSQL
- Completed: Schema, migrations, API CRUD, interface completa com pesquisa
- Current iteration: MVP completo
